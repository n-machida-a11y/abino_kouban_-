# abino_VBA

工事番号管理・請求書提出依頼書作成のExcel VBAコード一式

## ファイル構成

### インストーラー
- `VBAインストーラー.bas` - VBA一括更新用（メインメンテナンスツール）

### 標準モジュール (.bas)
- `設定用コード.bas` - 共通定数（シート名、パスワード、セル設定シート名）
- `呼び出し.bas` - 共通ヘルパー（ファイルパス取得、シート保護、フィルタクリア等）
- `PDF作成.bas` - 依頼書のPDF出力
- `登録フォームを開く.bas` - 登録フォーム呼び出し
- `削除フォームを開く.bas` - 削除フォーム呼び出し
- `更新.bas` - 工事番号一覧・依頼履歴の更新

### ユーザーフォーム (.frm + .frx)
- `依頼書作成.frm` - 請求書提出依頼書作成フォーム（メイン）
- `登録ボタン.frm` - 新規工事登録フォーム
- `再登録.frm` - 既存工事の再編集フォーム
- `削除フォーム.frm` - 工事削除フォーム
- `工事名称選択.frm` - 担当者＆工事名称選択ダイアログ

### クラスモジュール (.cls)
- `ThisWorkbook.cls` - ブック起動時のフィルタクリア・自動保護

## 使い方

### 初回セットアップ（各PCで1回だけ）

1. **マクロセキュリティ設定**
   - Excel → ファイル → オプション → セキュリティセンター → セキュリティセンターの設定 → マクロの設定
   - ☑ **「VBAプロジェクトオブジェクトモデルへのアクセスを信頼する」**

2. **VBAインストーラーをインポート**
   - VBAエディタ（Alt+F11）→ ファイル → ファイルのインポート → `VBAインストーラー.bas`

3. **このリポジトリをクローンまたはZIPダウンロード**
   - `Code` 緑ボタン → Download ZIP → 解凍

### 通常のVBA一括更新

1. **Alt+F8** でマクロ一覧
2. **`InstallAll`** を実行
3. ダウンロードしたフォルダを選択
4. 自動で `.bas` ファイルと `ThisWorkbook` が更新される

⚠️ `.frm` ファイルは上書きされません（手動でつけたコントロール名・キャプション保持のため）

### フォームのコードだけ修正したい場合

VBAエディタでフォームを開いて F7 でコード画面に入り、該当関数を手動編集。
フォーム自体を削除・再インポートしないので、コントロール名は保持されます。

## 設計メモ

### シート保護
- 保護パスワード: `kouji`
- 請求書提出依頼書: 完全保護（マクロ専用）
- 工事番号一覧・依頼履歴: データ保護（フィルタ可、編集不可）

### 明細JSON保存
- 共有マスターファイル（工事番号管理表）の **依頼履歴シート Z列** に明細をJSON形式で保存
- 再編集時に自動復元
- フォーマット: `[{"name":"xxx","qty":1,"unit":"式","amount":10000},...]`

### セル設定の動的管理
- **管理Excelの「依頼書セル設定」シート** に転記先セル位置を一覧で持つ
- 請求書提出依頼書のレイアウトを変えたら、このシートのB列を編集するだけで対応可能
- VBA改修不要

### 工事番号採番ルール
```
03-YY XX-ZZZ
├─ 03: 固定プレフィックス
├─ YY: 年度（下2桁、6月開始）
├─ XX: 担当者番号（2桁ゼロ埋め）
└─ ZZZ: 年度内連番（3桁ゼロ埋め）
```
